# Sistema de Gestão de Notas em Python 🎓🐍

Um sistema desenvolvido em Python para gerenciar o cadastro de notas de alunos, calcular a média aritmética e determinar a situação final (Aprovado/Reprovado). 

Este pequeno projeto foi desenvolvido como atividade prática da disciplina de Linguagem de Programação do curso de Análise e Desenvolvimento de Sistemas (ADS). O objetivo principal foi consolidar os fundamentos básicos da linguagem e desenvolver autonomia na construção de lógica limpa.

## 🚀 Conceitos Aplicados
Embora seja uma aplicação de terminal simples, o desenvolvimento focou em estruturar corretamente o raciocínio lógico:
* **Controle de Fluxo:** Utilização de laços de repetição contínuos (`while True`) para a entrada dinâmica de dados.
* **Interrupção de Ciclos:** Aplicação do comando `break` para encerrar o script no momento exato definido pelo usuário, sem quebrar as validações seguintes.
* **Estruturas Condicionais:** Lógica de decisão (`if/else`) para bloqueio de notas inválidas e cálculo do status de aprovação.
* **Modularização:** Código totalmente dividido em funções (`def`) com responsabilidades únicas, facilitando a manutenção e a leitura.
